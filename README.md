# Owais Raza — Soft Editorial Portfolio

This version follows the second visual reference more closely:
- warm cream background
- sage green hero field
- bold clean typography
- restrained red/yellow accents
- large readable text
- editorial card layouts
- responsive, mobile-first sizing

## Publish

Upload `index.html`, `style.css`, `script.js`, and `README.md` to the root of the `main` branch in `owaisraza40.github.io`.

In GitHub:
Settings → Pages → Deploy from a branch → `main` → `/(root)`.

Before the final publish, replace the placeholder LinkedIn URL and email address in `index.html`.
