# Owais Raza — GitHub Pages Portfolio

Personal portfolio website for **Owais Raza**.

## Deploy

1. Create a repository named `owaisraza40.github.io`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch → main → /(root)**.
5. Your site will be available at `https://owaisraza40.github.io`.

## Before publishing

- Replace `your-email@example.com` with your actual public email.
- Replace the LinkedIn placeholder with your LinkedIn profile URL.
- Add more projects as they become portfolio-ready.
